# HeyKobi downloads

Downloads for **Jarvis for Mac** and **Kobi** (the Android companion app). Source code isn't published here.

**Website and install guide:** https://heykobi.heykobi.workers.dev

## Jarvis for Mac
- One-line install (Terminal): `curl -fsSL https://heykobi.heykobi.workers.dev/jarvis/install.sh | bash`
- Or download the DMG from the latest `jarvis-v…` release below.
- Requires a Mac with Apple silicon (M1 or newer), macOS 14+, 8 GB memory (16 GB recommended), about 6 GB free space.

## Kobi for Android
- Download the APK from the latest `kobi-v…` release below and open it on your phone.

Jarvis runs entirely on your Mac. See the website's privacy page for details.
Includes open-source software; licences are listed in each app under About / Credits.
